# ToolBox CN 产品体验改进记录

日期：2026-11-09；当前工作树版本：0.2.0-dev。保留原有视觉风格与 30 个工具，不重写应用、不新增依赖、不发布或部署。冻结的 0.1.0 产物保持原样。

## 先检查实际问题，再决定范围

以下来自本轮实际源码、390px 浏览器页面和操作检查，不是用户访谈结论，也不声称已测量推荐率或留存提升。

| 维度 | 实际发现 | 本轮处理 |
| --- | --- | --- |
| 首次使用 | 首页有技术工具名和分类，但没有直接完成普通任务的入口；单一目标仍需先认识工具名 | 搜索下方增加六个任务入口；照片压缩、链接二维码、文字对比、重复名单和字数统计直接打开目标工具，表格转换保留方向选择 |
| 搜索发现 | 实测“我想让照片小一点”和 can you help me clean duplicate text 无结果；过滤后无结果也没有保留查询、恢复全站搜索的动作 | 本地任务/同义词层参与排序，保留转换方向优先；增加“搜索全部工具”；PDF/Word 文件转换无结果时明确边界 |
| 工具交互 | 所有错误共用“请检查输入内容、选项和格式”；多数按钮只写“运行转换/开始处理”；合法空 Base64 结果完全不显示 | 单独维护双语动作和恢复提示；加入处理/完成状态、重复点击防护，空结果可复制和下载；更换输入后过期结果不覆盖 |
| 移动体验 | 实测部分入口高 16–32px、搜索建议高 18px，输入字号 13px；侧栏无遮罩，Escape 会离开工具页；原生文件按钮显示英文 | 主要触控入口至少 44px、输入 16px；任务入口放在手机首屏；导航遮罩、焦点循环/恢复、关闭行为、旋转后滚动恢复；文件入口使用现有中文标签 |
| 一致性 | 空收藏、空历史、无搜索结果共用同一段提示；图片修改质量后仍展示上次结果 | 根据场景给下一步；统一结果区和操作反馈；质量改变清除旧图片结果；相同文本明确显示“没有差异” |
| 隐私信任 | 只有本地处理标识与页尾说明，不区分加载需要联网和处理发生本地；没有安全分享当前工具的入口 | 可展开的数据说明讲清存储范围；分享只复制工具 URL，去掉 query 和旧 fragment，不带用户输入 |
| 产品身份与项目呈现 | README 主要列功能，缺少“为什么我会用”和当前版本立即体验路径；静态“本次新增22项”继续占首页位置 | 将该位置改成任务发现，保留原有推荐/分类；中英文 README 加任务故事、区别、当前版本与本地启动说明，使用独立目录的新截图 |

## 强约束下的产品决定

- 不加工具。一个明确任务直接到工具；只有转换方向确实需要选择时才给候选结果，不增加新向导。
- 不宣称任意文件转换或智能理解。文档对比仍粘贴文字，转换只连接已有功能；搜索是本地规则和词库。
- 沿用现有紫色、字体、侧栏、卡片与主题；交互修补集中在 usability.css，原 style.css 与 density.css 未改。
- 默认中文和英文并存，收藏/最近记录结构不变；没有新增账号、统计、上传或第三方依赖。
- 新交互记录为 0.2.0-dev，不将它伪装为已冻结的 0.1.0 发布物。

## 关键实现

- src/tasks.js：任务文案、别名、已有工具 ID 和直达目标；Wi-Fi 请求优先找到 Wi-Fi 二维码。
- src/tool-ux.js：双语主动作、针对工具的恢复提示，以及只携带工具位置的分享链接。
- src/App.vue：结果状态与异步过期检查、复制/空下载、移动导航、上下文空状态、隐私说明。
- src/usability.css：移动触控、字体、结果操作和抽屉样式，继续使用原设计变量。
- tests/product-ux.test.js 与 product-ux.spec.js：新增任务查找、边界、状态、分享和移动交互验证。
