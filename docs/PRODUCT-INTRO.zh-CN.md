# ToolBox CN：让日常小事，更简单

想把照片变小、给链接做二维码，或清理一份重复名单？不用先记住技术名词，直接说出想做的事。

ToolBox CN 把 30 个可用工具组织成日常任务。目标明确的任务一步打开工具；需要选择方向的数据转换再展示候选项。工具页有示例、具体的出错建议、完成反馈，以及复制和下载入口。

默认简体中文，支持英文和深浅主题；手机上也能选择图片、粘贴文字和保存结果。处理在浏览器中完成，收藏与最近使用只记工具，不记输入。分享工具链接不会带上处理内容。

目前没有公开演示站。当前工作树版本 0.2.0-dev，可在本地运行 `npm ci`、`npm run dev`，打开 http://127.0.0.1:5178/ 体验。之前的 0.1.0 ZIP 是独立、冻结的候选版本，不包含本轮新增体验。

这不是任意文件转换服务：文档对比需要复制文字，格式互转目前支持 JSON/YAML/CSV 等已实现的工具，PDF/Word 文件转换尚不支持。首次加载仍需联网；本地处理不等于托管网站没有常规资源访问日志。

本项目基于 IT-Tools 并保留 GPL、版权和对应源码。无账号门槛，无虚构用户量或使用排行榜。截图、实现证据和测试边界见 [产品改进报告](PRODUCT-IMPROVEMENTS.zh-CN.md)。
